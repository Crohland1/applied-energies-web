Drilling & Shot Report Manager — Quick Instructions

1. Start a report

Tap + New document, choose STRAIGHT or OFFSET columns, and fill in the customer, drilling, and shot information.

2. Enter the drill pattern

Each square represents a hole. Enter overburden (up to 2 digits) at the top left, an optional note at the top right, and drilled depth at the bottom right. Notes do not affect calculations. Swipe sideways to see more columns.

3. Color-code holes

Press and hold a square to choose a manual color. You can also set yellow, orange, and red overburden thresholds to color holes automatically when their values are greater than the entered threshold. Manual colors take priority.

4. Pages and corrections

Use + Add Page to continue a report. Totals include all pages. Use the arrow buttons to shift the current page's hole entries, or Delete Page to remove an extra page. Finalize report updates report totals without filling blank holes.

5. Tonnage and totals

Enter a pattern such as 10 x 13, select the material, and enter drilled depths to calculate estimated tonnage. You can change the material weight for this report or enter tonnage manually.

6. Save, print, and share

Tap Save document to store the report in this browser on this device. Generate PDF / Print opens your device's print options. Share Editable Report sends or downloads a JSON report file; the recipient uses Import Editable Report to open an editable copy.

7. Backups and offline access

Use Export Backup regularly, and Restore Backup to import saved reports. Reports are not automatically synced between devices. An installed web app may work offline after its files are cached; first test it with the internet turned off.

Tip: Tap Help / Instructions in the top bar to reopen these instructions anytime.
